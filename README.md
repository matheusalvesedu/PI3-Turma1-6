# Projeto Integrador III - Super ID

O **Super ID** é um sistema de gerenciamento de autenticações desenvolvido como parte do Projeto Integrador III do curso de Engenharia de Software. Seu objetivo é criar um ecossistema completo para **criação de contas, armazenamento seguro de senhas e autenticação sem o uso de senhas**, voltado para fins educacionais.

> Este projeto está em **desenvolvimento** e **não atende aos padrões avançados de segurança da informação**, sendo voltado exclusivamente para aprendizado técnico.

---

## Visão Geral

O sistema é dividido em duas partes principais:

- **Aplicativo Mobile (Android)**  
  Desenvolvido em **Kotlin**, o app permite que o usuário final cadastre, visualize e gerencie suas credenciais de forma segura.

- **Integração Web (API + Firebase Functions)**  
  Permite que sites parceiros utilizem o **Super ID** como método de login, integrando também outros autenticadores (como Google).

## Tecnologias Utilizadas

- Kotlin (Android / Jetpack Compose)
- Firebase Authentication
- Firebase Firestore
- Firebase Functions
- HTML & CSS (para integração web)

---

## Funcionalidades Esperadas

- Cadastro e login de usuários via Firebase
- Armazenamento seguro de senhas
- Listagem filtrada de credenciais por categoria
- Integração com login em sites parceiros (via API)
- Tela de recuperação de conta
